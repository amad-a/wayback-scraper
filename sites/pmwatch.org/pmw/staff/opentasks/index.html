Open Tasks
If you would like to volunteer to one of the tasks below, please drop a note to pmwatch@zworg.com

Content editor

Collects urls of sites that are of interest to PMW.

Palestinian children victims

Collects information for the Palestinian children victim page.

Talking points editor

Maintains the talking points page. Adds information, double checks facts, etc.

Media contact information

Builds database of names, email addresses, etc., of editors, journalists, and other media actors. Supplement the email journalist page, the columnist contact info page, the newspaper contact information pages.

Media map editor

Maintains the media landscape page.

Chronology Editor

Builds a chronology of main events since the start of the current Intifadha.
