Palestine Media Watch contact information


Whenever you send a letter to any media outlet, newspaper, TV, radio, etc., please cc or bcc us at:

pmw-letters@egroups.com

If you have an action alert you wish to turn members' attention to, please send it to:

pmw-alerts@egroups.com

If you come across an article you think would be of interest to all to read, please send it to:

pmw-features@egroups.com

If you have a column or a piece YOU have written and would like to have PMWatch help you place it in a publication, please send it to:

pmw-columns@egroups.com

If and when the media (journalist, columnist, etc.) responds to you, please the communication to:

pmw-mediafeedback@egroups.com

If you find something you don't like about the PMWatch site, something that could be improved, an idea for making the site better, email to:

pmw-quality@egroups.com

If you have a question you would like help on researching, email:

pmw-research@egroups.com

Any other suggestions, email:

pmw-suggestions@egroups.com
