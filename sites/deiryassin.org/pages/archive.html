Printable Files Directory

This directory allows you to download information and material intended for printing and or dissemination. The materials here are updated periodically so please check back often. Note: All files are compressed using the "zip" format and require special software to make them useable. If you do not have Pkzip (dos), WinZip (win) or StuffIt (mac), please connect to the following link so as to obtain the necessary programs.

  • OS/2 PKZIP (ver 1.02) compressor/extractor
