Palestine Online is an archive of the early Palestinian web (with most webpages created between 1996-2004). The webpages were collected and scraped from the Internet Archive’s Wayback Machine, and are re-presented here with the addition of a number of enhancements to make the archive more accessible and easy to use, including:

  • Period correct browser interface, based on Internet Explorer 5
  • Indexed, organized, and searchable webpages
  • Fixed text encoding where broken
  • Disabled links for never archived pages
  • Converted and playable audio files
  • Image previews on hover
  • In-page machine translation between Arabic and English (Only on Chrome)

Palestine Online uses a number of open source projects to help with this, including 98.css, a CSS library that looks like Windows 98, Ruffle, a Macromedia/Adobe Flash emulator, and Webamp, a reimplementation of Winamp.
