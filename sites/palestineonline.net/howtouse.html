  1. Sitelist dropdown button

    Press to show a dropdown list of pages to start your web surfing journey, sorted in a number of categories.

  2. Search bar

    Use to search and find any page in the archive.

    http://palestineonline.net/

  3. Favorite button

    ☆

  4. Back + Forward

    Go to previous or next page in browser history.

  5. Home

    Go to the Palestine Online homepage, the page that was in the browser when you first visited palestineonline.net.

  6. Favorites

    View pages you have saved using the favorite button (only stored locally on your computer).

  7. History

    View pages you have visited previously (only stored locally on your computer).

  8. Random

    Takes you to a random page in the archive.

  9. Source

    View the page on the Internet Archive’s Wayback Machine.

  10. Translate

    (Available on Google Chrome only) Translates the page between English <-> Arabic using Google’s Translator API.

  11. Share

    Share the current page via email, text, or copy+paste.

  12. Print

    Print the page to PDF or an actual printer. Prints QR codes at the bottom of each page that contain its link on Palestine Online.

  13. Background

    Click to change the tiled background image. Clicking the left side of the screen changes to a lighter color, the right side to a darker color.
