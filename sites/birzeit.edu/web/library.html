World Wide Web Center

Existing printed resources and library needs

Last updated: 21 August 1997

The newly established World Wide Web Center at Birzeit hopes to establish a good Web reference library. As we were a little slow to get on the Web here and knowledge of the Internet is generally limited in Palestine, we would be very happy to receive old copies of any Web-related magazines and books that you may have lying around. The PC platform for all donations and CD ROMs should be IBM, not Macintosh.

Below is a list of current resources, which will be updated as and when donations are received. The university unfortunately has no funds to pay for postage costs of donations. Second copies of books mentioned below are appreciated, as this will enable a reference copy to remain in the library while others are lent out.


BOOKS

    What we have:
  • The Web Page Design Cookbook, Horton, Taylor, Ignacio and Hoft, John Wiley and Sons, 1996. Donated by Wendy Abu Al-Hawa.
  • HTML 3.2 Visual Quick Reference, Dean Scharf, Que, 1997. Donated by Conrad Taylor.
  • More Web Publishing with HTML In a Week, Lemay, Sams.net Publishing, 1995. Purchased by Birzeit WWW Center.
  • Web Weaving, Tilton, Jones, Steadman, Addison Wesley Developers Press, 1995. Purchased by Birzeit WWW Center.
  • Foundations of World Wide Web Programming with HTML and CGI, Tittel, Gaither, Hassinger and Erwin, IDG Books Worldwide, 1995. Purchased by Birzeit WWW Center.
  • The Windows Internet Tour Guide: Cruising the Internet the Easy Way, Michael Fraase, Ventana Press, 1994. Donated by Samia A. Halaby.
  • Welcome to... Internet: From Mystery to Mastery, Tom Badgett and Corey Sandler, MIS Press, 1993. Donated by Samia A. Halaby.
    Books we need:
  • Introduction to HTML reference and workbooks
  • Advanced HTML reference and workbooks
  • CGI Scripts and Web-related programming, including JavaScript
  • Advanced Web features inluding VRML, database management, etc.
