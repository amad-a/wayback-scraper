Program Description

This is a 50 contact hour training program held in cooperation with The Maastricht School of Management.

This program targets Project managers, System developers, or Senior Programmers, who wish to acquire the skills necessary for designing and developing systems using Object Oriented methods.

The training will cover the system development life cycle. Applications will be developed using Object Oriented System Engineering tool that is a programming language independent tool. The tool is base on several components (C++, Java) but also applies to embedded legacy packages.

The program consists of one module in which several topics will be covered. Trainees will develop projects after finishing the program to practically apply methods and skills that they are trained on.

Program Outline

The Object Oriented System Development Program consists of seven main themes. The Following is a brief description of each topic.

System development
This is an introduction to the whole program, it introduces participants to system development characteristics, logical data flows, Hierarchical decomposition, and user views.

System life Cycle
This theme covers the system development life cycle, dealing with the process of change vs. Walk through concepts. It will also cover all system development phases and Object Oriented Methodology. It will start to teach participants the use of UML: OOSE Objector Development Tool on win95.

Object Oriented system developmen
The participants will learn object-oriented analysis, construction and testing. The module will cover the real time and DBMS Specialization and reusing components.

Testing and Implementation
This theme covers main methods used for testing and implementation such as: requirement approval, system verification, and component-based testing module and system integration.

Managing Object Oriented Software Engineering
The theme covers several topics that are hot issues in today’s programming: software assurance, Software matrices, CMU SEI Capability Maturity Module.

Other Object Oriented methods
The theme covers new emerging methods in object oriented methods such as the UML methodology, Component based development, OOA/ Coad-Yourdon, OOD Booch.

Case Study
This last theme gives some case studies that illustrate the methods covered in the previous themes. It will cover the CBD Demos by select and Dynasty, Recycling Device, ATM Device.

Training Requirements

    1. An active programming knowledge is not necessary due to current Component based development (priority will be given to participants with stronger experience).
    2. Participants must complete all requirements of a module and pass the evaluation criteria to qualify for the following module
    3. Participants must develop a project from their professional environments based on the skills acquired during the training. These projects will be required after modules 3 and 6. The projects will be evaluated.
