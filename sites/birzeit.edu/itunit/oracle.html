Oracle Programming Certificate

    Module I (15 hours)

    • Title: Introduction to SQL
    • Lecturer: Wahbeh Musa
    • Dates: 6, 8 March 98
    • Prerequisites: Background in database programming and concepts
    • Description: Introduction to SQL, Functions, Extracting data from more than one table, Formatting SQL outputs.

    Module II (15 hours)

    • Title: Programming the ORACLE7 Engine with PL/SQL
    • Lecturer: Ammar Sajdi/ Amjad Ma'abreh
    • Dates: 13, 14 March 98
    • Prerequisites: SQL Programming
    • Description: This course is intended for advanced ORACLE7 programmers who wish to explore the techniques of ORACLE7 programming concepts: Overview of SQL, PL/SQL, Declarative Data Integrity, Database Stored Procedures and Packages, Database Triggers, Database Security

    Module III (36 hours)

    • Title: Programming with Developer 2000
    • Lecturer: Ammar Sajdi/ Amjad Ma'abreh,
    • Dates: 15, 16, 17, 18, 19 March 98
    • Prerequisites: PLSQL Programming
    • Description: The participant will learn how to develop and implement forms and Menu applications with Developer/2000 FORMS 4.5 and will learn how to develop a variety of standard and custom reports using the reports component of Developer/2000 a client/server environment.

    Module IV (40 hours)

    • Title: Business System Modeling Using Designer/2000.
    • Lecturer: Saeed Abu Elnaj
    • Dates: 9,10,11,12,13 April 98
    • Prerequisites: PLSQL Programming & Developer 2000
    • Description: This module covers the main modeling techniques such as Process modeling, Entity Relationship modeling, Function decomposition, and Cross-referencing models. The emphasis will be on how to develop these modeling techniques using Designer/2000.

    Module V (40 hours)

    • Title: Design and Build Database Objects Using Designer/2000
    • Trainer: Saeed Abu Elnaj
    • Dates: 20, 21, 22, 23, 24 April 98
    • Prerequisites: Business System Modeling Using Designer/2000.
    • Description: This Module builds on Module IV, where system modeling is moved to the design phase. Designer/2000's Reports are used to verify the quality of the system models. Using Designer's Database Wizard entities are mapped to tables using the and attributes to columns, Relationships to foreign keys and unique identifiers to primary keys. This module will also cover the DDL generation, building views, writing triggers, creating packages and PLS/SQL in Designer/2000.

    Module VI (40 hours)

    • Title: Design and Build Applications Using Designer/2000
    • Trainer: Saeed Abu Elnaj
    • Dates: 29, 30 April 1, 2, 3 May 98
    • Prerequisites: Designing and Building Database Objects Using
    • Designer/2000
    • Description: This module covers the principals of application design and applying those principals using Designer/2000 tools. It covers matrix modeling, the mapping of functions into modules using the Application Wizard, determining module types, generating modules using the Application Generator, generating menus, and Module Structure Diagrammer.

    Training Requirements

    • Trainees must have strong programming skills and at least some experience in database programming (priority will be given to participants with stronger experience).
    • Participants must complete all requirements of a module and pass the evaluation criteria to qualify for the following module
    • Participants must develop a project from their professional environments based on the skills acquired during the training. These projects will be required after modules 3 and 6. These projects will be evaluated.

    Certification

    Participants that successfully complete the requirements for the program will receive an Oracle Developer Certificate offered by the IT Unit at Birzeit University.
