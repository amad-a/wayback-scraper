    Program Description

    CISCO Certified Network Associate Program is a 54 hours training program. This information-packed program gives you the Hands-On experience you need for configuring your Cisco routers in multiprotocol networks. Commands ranging from address configuration to management and verification testing will be demonstrated and discussed. Participants will learn IP, IPX Protocols will be able to configure RIP, IGRP and OSPF routing protocols. The program is designed to provide participants with the knowledge and experiences needed to successfully configure Cisco networks and to pass the CCNA Exam provided by CISCO International.

    Program Outline

    The Program consists of three modules. The Following is a brief description of each module

    Module I: Introduction to CISCO Routers Configuration

    Trainer:

    Usama Houlila

    Prerequisites:

    Very Good knowledge in TCP/IP

    Evaluation:

    CCNA Exam

    This module will cover the following:
    Cisco Configuration for IP, IPX, and AppleTalk Routing
    Cisco Router Software Configuration and Management
    Network Addressing Basics Including IP Address Classes, Subnet Masks, and DNS
    Cisco IP Routing - RIP and IGRP
    Network Testing Commands - Telnet, PING, Trace, and Debug
    Cisco Wide Area Networking - HDLC, PPP, Frame Relay, X.25
    IP Subnetting

    Module II: Advanced Cisco Router Configuration

    Trainer:

    Usama Houlila

    Prerequisites:

    Introduction to Cisco routers

    Evaluation:

    CCNA Exam

    This module will cover:
    Cisco Router Software Configuration and Management
    Transparent, Source Route Transparent, Encapsulated, and Translational Bridging
    Cisco IP Routing - IGRP, EIGRP, OSPF
    Variable Length Subnet Masking (VLSM)
    Ethernet to Token Ring Bridging
    Priority Output Queuing
    Frame Relay Configuration
    IP Tunneling
    Extended and Complex Access Lists
    ISDN Configuration
    How to Calculate Default Metrics for Route Redistribution
    To Enable Dial-On-Demand Routing (DDR)

    Module II: Cisco Internetwork Troubleshooting

    Trainer:

    Usama Houlila

    Prerequisites:

    Advanced CISCO Router configuration

    Evaluation:

    CCNA Exam

    The module will cover the following:
    When to Use Specific Cisco Commands: show, write, debug, ping, and trace
    LAN/WAN Problem Isolation
    Ethernet, Fast Ethernet, and Token Ring Troubleshooting
    How to Use Protocol Analyzers
    IP, IPX, AppleTalk, HDLC, ISDN, BRI, and X.25 Traffic Troubleshooting

    Training Requirements

    1. Trainees must have strong knowledge in TCP/IP and a good experience in networking. (priority will be given to participants with stronger experience).
    2. Trainees will be given the course material one week before the start of the course and at the first day they apply for an exam to evaluate their knowledge level.
    3. After finishing the program participants are urged to take the CCNA Exam.
