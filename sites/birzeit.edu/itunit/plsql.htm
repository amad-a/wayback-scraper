    Program Description

    This 120 contact hour training program targets software developers and programmers who wish to acquire the skills necessary for designing and developing applications using ORACLE

    The training will be condensed and hands on. It will cover the full Oracle application development life cycle. It includes practical training where the trainees apply the concepts acquired by developing project from the environments they work in.

    The program is broken down into two modules. At the end of any module participants will be given an ORACLE CERTIFICATE for the modules they finished successfully
