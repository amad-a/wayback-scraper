 RECENT SERVICE:

SCANNING:

   Library patrons may scan any (image or text) for a fee of 1.5 NIS for each file (if they want to scan {save on disk only} without colored printing), or a fee of 5 NIS for each file (if they want to scan and print colored images).


RECENT APPLICATION:

    The Library began to use a circulation Software, starting from the beginning of March 1999. This will help library employees in giving the library patrons a better, more accurate and a faster service.

Any Library Patron who exceeds the due date of returning borrowed book(s), will be subjected to a fine.
